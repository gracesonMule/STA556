1. Codespaces
What is a GitHub Codespace, and why does STA 556 use one?

GitHub Codespaces is a cloud hosted environment. We use it in STA 556 to ensure compatibility.

2. Git vs. GitHub
Explain the difference between Git and GitHub.

Git is a version control service and GitHub is a cloud service to store your Git.

3. Repository root
Why do course instructions assume commands are run from the repository root?

It is used as a standard starting point for all directories/files ensure proper reference to dirs/files.

4. Commit vs. push
What is the difference between committing and pushing?

Committing tracks the change and pushing it updates the change to the GitHub.

5. Notebook vs. script
When would you choose a Jupyter notebook? When would you choose a Python script?

When you need a file that reads like a paper with visuals and text, use a Notebook. When you just need to excute a script use a Python file.

6. Reproducibility
Why are relative paths and a repository-defined environment useful?

Relative paths allow you reference files without needing an absolute path that may change from system to system. A repository-defined environment allows you to control specific package versions for reproducability.
